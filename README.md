## Projetos em destaque

### Pipeline de Dados Educacionais

Pipeline reprodutível de Engenharia de Dados e Analytics Engineering para dados oficiais do Inep. Organiza uma série histórica de 2007 a 2023 em camadas **Raw → Bronze → Silver → Gold** e entrega um modelo analítico para Power BI.

**Destaques:** processamento de XLS, XLSX, XLSB, CSV e TXT; inventário de 54 arquivos; hashes SHA-256; validações por camada; modelo dimensional com cinco dimensões e cinco tabelas fato; testes e CI.

**Tecnologias:** Python, Pandas, Power BI, DAX e GitHub Actions.

[Ver código e documentação](https://github.com/miltonRafa/portfolio-pipeline-dados-educacionais)

### AgendeCom

Plataforma responsiva para profissionais autônomos gerenciarem serviços, clientes, disponibilidade e agenda. O cliente pode solicitar um horário por um link público, sem cadastro obrigatório.

**Destaques:** agenda e bloqueio de horários; sinais via Pix; lista de espera; relatórios operacionais; área do cliente; assinatura com Stripe; testes automatizados.

**Tecnologias:** React, TypeScript, Vite, Tailwind CSS, Node.js, Express, Firebase, Google Cloud Run, Stripe, Vitest e Supertest.

[Ver estudo de caso](https://github.com/miltonRafa/portfolio-publico-agendecom) · [Acessar aplicação](https://agenda-b4b7c.web.app)
